## 📌 Repository Overview

This repository captures my exploration of the **Python 3** ecosystem as a 3rd-semester B.Tech Computer Science & Engineering student. 

It spans from core language features (dynamic typing, list/dict comprehensions, decorators) to practical application modules: file I/O streams with JSON/CSV, basic data science routines with NumPy and Matplotlib, and filesystem automation scripts.

## ⚙️ Setup & Virtual Environment

```bash
# 1. Clone repository
git clone https://github.com/bhavishya0922/python-programming.git
cd python-programming

# 2. Create isolated virtual environment
python -m venv venv

# 3. Activate environment
# On Linux/macOS:
source venv/bin/activate
# On Windows PowerShell:
.\venv\Scripts\Activate.ps1

# 4. Install dependencies
pip install -r requirements.txt

# 5. Run any script
python 01-basics/01_variables_and_types.py
```
